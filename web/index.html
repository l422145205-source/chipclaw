GET STARTED

先体验，再复现。

轻量回放无需 GPU。实时检索需要另行准备模型和手册。

01 / 无模型体验

python -m pip install -r requirements-web.txt
python -m uvicorn chipclaw.workbench:app --host 127.0.0.1 --port 8000

打开 http://127.0.0.1:8000。公开的运行记录与原始文件哈希一起保存在 web/demo。

02 / 实时工作台

安装完整依赖并完成语料、索引和权重准备后，设置 CHIPCLAW_API_WARMUP=none，再启动：

python -m uvicorn chipclaw.api:app --host 127.0.0.1 --port 8000

本页面调用 /evidence，不依赖 Ollama 生成。首次请求加载模型可能较慢。已有 /ask 生成接口保留，但本轮证据实验不等同于生成质量实验。

03 / 复现实验

阅读仓库的 PUBLICATION.md 和 README-v4.md。大体积权重、厂商原始 PDF、环境缓存均不打包进 Git；公开代码与配置提供训练和数据构建入口。
